# วิธีเขียนบทเรียน Node + React

ผู้เรียนต้องอธิบายและดัดแปลงได้ ไม่ใช่เพียงคัดลอกจนชุดตรวจผ่าน

## ลำดับการสอน

1. เชื่อมกับสิ่งที่เพิ่งทำได้ และระบุปัญหาใหม่ที่ต้องแก้
2. อธิบายเหตุผลของเครื่องมือก่อนสั่งให้ใช้ แนะนำศัพท์ใหม่พร้อมตัวอย่างใกล้ตัว
3. ไล่โค้ดตามลำดับทำงานจริงด้วยค่าตัวอย่าง: ข้อมูลเริ่มจากไหน ผ่านอะไร และเปลี่ยนที่ใด
4. ระบุไฟล์ ตำแหน่งแก้ และการเตรียมที่จำเป็น แยกโค้ดเต็มที่รันได้ออกจาก fragment ที่ต้องวางในฟังก์ชัน
5. ให้ลงมือเรื่องเดียวต่อช่วง พร้อมผลที่มองเห็นได้และจุดเริ่มตรวจเมื่อผิด
6. ให้ทายผลก่อนเปลี่ยนตัวอย่างหนึ่งจุด แล้วทดลองและอธิบายสาเหตุด้วยคำของตัวเอง
7. ให้แนวคิดตรวจคำตอบหลังได้ลอง ไม่ใช้การผ่าน tests เป็นหลักฐานเดียวว่าเข้าใจแล้ว

## ตัวอย่างการแก้คำสอนห้วน

เดิม: “fetch แล้ว setTasks ใน useEffect”

ปรับ: “ตอนเปิดหน้าข้อมูลยังมาไม่ถึง ให้ tasks เริ่มเป็น [] เพื่อให้ map ทำงานได้ ระหว่างนี้แสดงกำลังโหลด หลังวาดหน้า effect จะขอรายการจาก Node เมื่อได้ response ให้ตรวจสถานะ อ่าน body ด้วย json() แล้วเรียก setTasks เพื่อแจ้ง React ให้วาดรายการใหม่ ถ้า API ตอบ 404 fetch ไม่ reject เอง จึงต้องตรวจ response.ok ก่อนอ่านข้อมูล”

จากนั้นให้ทายและทดลอง URL ผิด แล้วอธิบายว่าจุดไหนเป็นคนแสดง error และจุดไหนหยุด loading หลีกเลี่ยงคำว่า “effect รันครั้งเดียวเสมอ” เพราะระหว่างพัฒนา StrictMode อาจเพิ่มรอบ setup/cleanup

## ลำดับการอ่านและ UX

- แสดงทีละขั้น พร้อมตัวเลือกข้ามและปุ่มก่อนหน้า/ถัดไปที่คงอยู่ระหว่างเลื่อน
- ให้เลือกอ่านคู่โค้ด อ่านเต็มพื้นที่ หรือสามแผงได้จากทุกแท็บ และลากขยาย/ย่อได้จริง แยก toolbar ออกจากบทความเพื่อไม่ให้ทับข้อความระหว่างเลื่อน
- เมื่อเปลี่ยนขั้น กลับสู่ต้นขั้นใหม่และย้าย keyboard focus ไปหัวข้อ ไม่ทิ้งคนอ่านไว้กลางเนื้อหา
- บันทึกขั้นที่อ่านแยกตามบท กลับมาอ่านต่อได้ แต่ไม่แสดงว่าเรียนผ่านเพียงเพราะเปิดอ่าน
- วางเหตุผล การทำงาน ไฟล์ที่จะแก้ ตัวอย่าง และผลที่ควรเห็นในขั้นเดียวกัน
- พับเฉพาะโครงโค้ดสำหรับช่วยเขียนและแนวตอบ เหตุผลสำคัญต้องอ่านได้ทันที
- บทแนวคิดแบ่งเป็น เป้าหมาย/ศัพท์ → โค้ดและคำอธิบาย → ทดลอง จึงไม่ต้องสลับกลับไปตามหาโค้ดท้ายบท
- เรียง Node → React → Full Stack ให้ผู้เรียนทดสอบแต่ละฝั่งแยกได้ก่อนเชื่อม เพิ่มช่วง dependencies/config ที่ระบุโฟลเดอร์ คำสั่ง และผลตรวจพร้อมใช้งาน
- อ่านสไลด์จริงก่อนเลือกนามสกุลและรูป module ชุดฝึก Node ใช้ .js/CommonJS ส่วน React ใช้ .jsx; แยกความต่างของเวอร์ชัน ไลบรารี พอร์ต และ schema ไว้ตรงที่ผู้เรียนต้องตัดสินใจ

## ก่อนรับบทเรียนใหม่

ลองอ่านด้วยสมมติฐานว่ารู้เฉพาะบทก่อนหน้า: มีศัพท์ไหนที่ยังไม่ได้สอนไหม มีการข้ามจากตัวอย่างเล็กไปโค้ดเต็มหลายแนวคิดไหม ผู้เรียนรู้หรือไม่ว่าตอนนี้อยู่ไฟล์ใดและควรเห็นผลที่ไหน ถ้าลบเฉลยออก ยังมีคำอธิบายพอให้ลองเขียนและหาจุดผิดเองหรือไม่

แนวทางอ้างอิง: [IES: Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) โดยนำการสลับตัวอย่างกับโจทย์ฝึก การเชื่อมแนวคิดกับตัวอย่างรูปธรรม และคำถามเชิงเหตุผลมาปรับใช้กับการเขียนโปรแกรม ยังต้องรับ feedback จากผู้เรียนจริงเพื่อประเมินความเข้าใจ
