# ทดลองอ่านจากมุมผู้เริ่มต้น · 28 ตุลาคม 2026

นี่คือการไล่ตรวจเนื้อหาโดยจำกัดความรู้สมมติให้เท่าบทก่อนหน้า ไม่ใช่ผลทดลองกับมนุษย์จริง และไม่ใช้จำนวน tests ที่ผ่านเป็นคะแนนความเข้าใจ

## สิ่งที่พบหลังปรับรอบแรก

| ช่วงอ่าน | คำถามที่ผู้เรียนยังตอบไม่ได้จากข้อความเดิม | สิ่งที่แก้ |
|---|---|---|
| บท 00 | แค่แก้หัวเรื่อง ทำไมต้องรู้ npm, array, object และ API พร้อมกัน? ดูผลตรงไหน? | จำกัดเป้าหมายแรกเป็นข้อความและสี แยก Browser/Preview, App.jsx และ CSS พร้อมโค้ดที่ต้องเปลี่ยน ไม่สั่งตรวจ API ในการทดลองแรก |
| ตัวอย่างบท 00 | ในตัวอย่างเขียน My first page แต่ไฟล์ตั้งต้นจริงเป็น Hello Full Stack ต้องหาอันไหน? | ใช้ข้อความและ element เดียวกับไฟล์ตั้งต้นจริง แล้วแสดงเฉพาะบรรทัดที่ให้เปลี่ยนในขั้นถัดไป |
| บท 06 | `{ name }` มาจากไหน? เหตุใด Greeting จึงกลายเป็น MenuCard? | เริ่มด้วย props.name ก่อนรูป destructuring ไล่ข้อมูล Mali เข้า component แล้วพาแปลงชื่อไฟล์ ชื่อ component และ props สำหรับโจทย์ |
| บท 07 | `[likes, setLikes]` เป็นเลขสองตัวหรือ? ฟังก์ชันลูกศรสองชั้นทำงานตอนไหน? | แยกค่าอ่านกับฟังก์ชันเปลี่ยนค่า อธิบายฟังก์ชันรอคลิกกับฟังก์ชันคำนวณค่าใหม่ แล้วไล่หน้าจอจาก 0 เป็น 1 |
| บท 08 | event คืออะไร? ล้างช่องแล้วข้อความบันทึกหายด้วยหรือไม่? | อ่าน event.target.value ด้วยข้อมูลจริง แยก state ของช่องที่กำลังกรอกกับผลที่ยืนยันแล้ว และบอกตำแหน่งวาง fragment |

| UX | อ่านคำอธิบายแล้วต้องกลับขึ้นไปหาโค้ดหรือขั้นเดิม | แสดงทีละช่วง เก็บโค้ดกับคำอธิบายในช่วงเดียว มี navigation คงอยู่ระหว่างเลื่อน จำช่วงที่อ่าน และขยายแผงอ่านบน desktop |

## วิธีตรวจซ้ำ

ในแต่ละช่วง ให้ลองตอบก่อนเปิดแนวคิด: ต้องแก้ไฟล์ใด? ค่าเริ่มจากไหน? บรรทัดใดเปลี่ยนค่า? ผู้ใช้เห็นผลตรงไหน? เมื่อเปลี่ยนตัวอย่างหนึ่งจุด ผลควรต่างอย่างไร? ถ้าต้องนำความรู้ที่ยังไม่เคยสอนมาตอบ ให้ถือว่าเนื้อหายังขาดสะพาน

ตัวอย่างคำถามตรวจความเข้าใจ: เปลี่ยน price ที่แม่หรือที่ลูก? เหตุใดกดลดแล้วไม่ติดลบ? ทำไมข้อความสำเร็จต้องแยกจาก input? ทำไม 404 ต้องตรวจ response.ok? แต่ละข้อมีแนวคิดให้เปรียบเทียบหลังลองตอบ ไม่บังคับว่าผู้เรียนต้องใช้ถ้อยคำตรงเฉลย

## ขอบเขตของผล

รอบแรกตรวจละเอียดที่บท 00, 06–09 และจับมือทำทั้ง 5 Level ต่อมาขยายการตรวจและคำอธิบายใหม่ครบ 18 บทกับเวิร์กช็อป 7 ชุด จัด Node → React → Full Stack และตรวจ dependencies/ชนิดไฟล์กับสไลด์ต้นฉบับ ดู [การเทียบสไลด์และขอบเขตที่ทดสอบ](SLIDE_COURSE_COVERAGE.md)

การทดสอบ browser ตรวจการเปลี่ยนช่วง การกลับมาอ่านต่อ การลากแผงทั้งสองทิศทาง โหมดอ่านเต็มพื้นที่ และตำแหน่ง toolbar ซึ่งย้ายออกจากบทความแล้ว การประเมินความเข้าใจจริงยังต้องให้ผู้เริ่มต้นลองทำโจทย์ดัดแปลงโดยไม่คัดลอก และสังเกตจุดที่ต้องถามเพิ่ม
