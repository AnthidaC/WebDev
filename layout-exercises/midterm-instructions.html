🌿 Flora & Fauna Glasshouse

ระบบเว็บโปรโมทร้าน เมนูอาหาร และฟอร์มจองห้องสัมมนาเรือนกระจก

3 ชั่วโมง (แนะนำ) เวลาในการทำสอบ
3 หน้าเว็บแยกกัน โครงสร้าง HTML & CSS
30 คะแนนเต็ม สัดส่วนการประเมินผล

📌 ข้อมูลแนะนำทั่วไป

ข้อสอบปฏิบัติฉบับนี้มีวัตถุประสงค์เพื่อวัดทักษะในการเขียนโครงสร้างภาษา HTML5 Semantic Tags และการเขียนตกแต่งจัดหน้าเลย์เอาต์ด้วย Vanilla CSS (CSS Flexbox, CSS Grid, Advanced Selector, SVG styling, Responsive Web Design) จากความกว้างหน้าจอระดับพีซีจนถึงโทรศัพท์มือถือ โดยไม่มีการนำเข้า Frameworks (เช่น Bootstrap หรือ TailwindCSS) และไม่มีการใช้คำสั่ง JavaScript

⚠️ ข้อห้ามและกติกาสำคัญในการสอบ

  • ห้ามเชื่อมโยงไลบรารี CSS หรือไอคอนภายนอกใด ๆ ให้เขียน Vanilla CSS ลงใน midterm.css เท่านั้น
  • ห้ามใช้คำสั่ง JavaScript เพื่อสร้างการตอบสนอง ทุกพฤติกรรม เช่น การเปลี่ยนแท็บ การไฮไลท์ หรือการเลือกแพ็กเกจ จะต้องควบคุมผ่าน CSS ทั้งสิ้น
  • ไฟล์ HTML ทั้ง 3 ไฟล์เริ่มต้นได้รับการล้างข้อมูลจนเหลือเพียงโครงสร้างเอกสารเปล่า คุณต้องเขียนแท็กภายใน <body> เองทั้งหมด

🎨 ข้อกำหนดการออกแบบ สี และฟอนต์ (Design System Specs)

ผู้เรียนต้องเลือกใช้รหัสสีและฟอนต์ตามเกณฑ์การออกแบบอัตลักษณ์ของคาเฟ่ (Brand Identity) ดังต่อไปนี้:

🖌️ จานสีธีมธรรมชาติระดับพรีเมียม (Color Tokens)

ชื่อตัวแปร CSS รหัสสี Hex Code การใช้งานหลักในข้อสอบ
--primary-color #1b3b2b (Deep Forest Green) สีหลักของแบรนด์, พื้นหลังปุ่มหลัก, สีฟอนต์หัวข้อโลโก้, สีรางเลือกหลัก
--accent-color #c49a6c (Antique Gold) สีทองประดับ, สีป้ายราคา, สีไฮไลท์เส้นขอบเมื่อโฟกัส หรือเมื่อ Hover/Checked
--accent-light #f5efe6 (Sand Cream) สีครีมพื้นหลังปุ่มรอง หรือสีจางสำหรับสถานะ Hover ของเมนูนำทาง
--bg-light #faf8f5 (Ivory White) สีพื้นหลังหลักของทุกหน้าจอ เพิ่มความรู้สึกสว่าง อุ่น และสะอาดแบบธรรมชาติ
--text-dark #1b2520 (Charcoal Black) สีข้อความหลักทั่วไป อ่านง่ายสบายตาบนพื้นสีครีมงาช้าง
--text-muted #6c7870 (Sage Muted) สีเทาอมเขียวจาง สำหรับข้อความอธิบายย่อย และเส้นกรอบทั่วไป
--bestseller-color #9e2a2b (Ruby Red) สีแดงพิเศษสำหรับป้ายประดับกล่องสินค้าขายดี (Bestseller Badge)
--white #ffffff (Pure White) สีขาวพื้นการ์ด และสีตัวอักษรของแบนเนอร์ Hero

✍️ แบบอักษรประจำแบรนด์ (Typography)

  • ฟอนต์หัวเรื่องเด่น (Serif headings): ใช้ 'Playfair Display', serif สำหรับข้อความ <h1>, <h2>, <h3> และโลโก้ร้านเพื่อสื่ออารมณ์หรูหราคลาสสิก
  • ฟอนต์เนื้อหาทั่วไป (Sans-serif body): ใช้ 'Sarabun', 'Sora', sans-serif สำหรับย่อหน้า <p>, ป้าย <label>, ตาราง และส่วนอื่น ๆ เพื่อให้อ่านข้อความและตัวเลขได้ชัดเจนในทุกขนาดอุปกรณ์

1. หน้าข้อมูลร้าน midterm-shop.html (7 คะแนน)

เขียนโครงสร้างหน้าหลักแสดงประวัติร้าน สถิติของคาเฟ่ และแกลเลอรี Bento Grid โชว์บรรยากาศ

🔍 โครงสร้าง HTML ที่ต้องเขียนขึ้นเองภายใน body:

  1. แถบเมนูนำทาง (navbar):
    • ใช้โครงสร้างแท็ก <header class="navbar"> ครอบกล่องจัดแนวด้านใน <div class="nav-container">
    • ด้านซ้ายมีโลโก้ <div class="logo">🌿 Flora & Fauna</div>
    • ด้านขวามีกลุ่มลิงก์เมนู <nav class="nav-links"> ประกอบด้วย <a> จำนวน 3 ลิงก์เชื่อมโยงไปยัง 3 หน้าปฏิบัติ โดยหน้าแรกต้องใส่คลาส active
  2. ส่วนฮีโร่แบนเนอร์ (hero):
    • ใช้แท็ก <section class="hero"> ด้านในมีกล่องเคลือบพื้นสีเข้ม <div class="hero-overlay"></div>
    • มีกล่องข้อความ <div class="hero-content"> บรรจุ <span class="badge"> หัวเรื่อง <h1> ข้อความคำโปรย <p> และปุ่มกดจองโต๊ะ <a class="btn btn-primary">
  3. ประวัติร้านและตัวเลขสถิติ (about-section):
    • ใช้แท็ก <main class="container"> คุมกรอบเนื้อหาถัดมา ด้านในสร้าง <section class="about-section">
    • ฝั่งซ้ายเป็นกล่องข้อความ <div class="about-text"> ประกอบด้วย <h2> ยินดีต้อนรับสู่ Flora & Fauna และคำอธิบายร้าน
    • ฝั่งขวาเป็นกล่องสถิติ <div class="stats-grid"> บรรจุข้อมูลสถิติย่อย 3 ชิ้นในกล่องคลาส stat-item (แต่ละกล่องมีค่าตัวเลข .stat-number และป้ายชื่อ .stat-label)
  4. คลังภาพเรือนกระจก (gallery-section):
    • ใช้แท็ก <section class="gallery-section"> มีกล่องครอบหัวเรื่อง <div class="section-header">
    • กล่องบอร์ดกริด <div class="gallery-grid"> ภายในประกอบด้วยรูปภาพ 5 ภาพครอบในคลาส <div class="gallery-item item-1"> ถึง item-5
    • แต่ละภาพต้องมีโครงสร้างย่อย: <div class="gallery-img-wrapper"><img src="..."></div> และ <div class="gallery-caption">...</div>
  5. ฟุตเตอร์ (footer):
    • ใช้แท็ก <footer class="footer"> บรรจุกล่องคุมระยะ .container และข้อความลิขสิทธิ์ <p>

2. หน้ารายละเอียดเมนู midterm-menu.html (10 คะแนน)

เขียนโครงสร้างหน้าแสดงรายการเครื่องดื่ม เบเกอรี่ และบริการพื้นที่จองด้วยระบบ Grid Layout ที่มีการ์ดขนาดความสูงเท่ากัน และจัดปุ่มชิดล่างเสมอ

🔍 โครงสร้าง HTML ที่ต้องเขียนขึ้นเองภายใน body:

  1. ส่วนหัวข้อมูลแนะนำ (menu-intro):
    • ใช้แท็ก <main class="container page-content"> ถัดจากแถบเมนูนำทาง
    • ด้านในใส่ <section class="menu-intro"> ประกอบด้วย <h1> เมนูและแพ็กเกจบริการ และย่อหน้า <p> อธิบายคำเชิญชวน
  2. ปุ่มตัวเลือกหมวดหมู่ (category-nav):
    • ใช้แท็ก <nav class="category-nav"> บรรจุ <a> จำนวน 4 ตัว ได้แก่ ทั้งหมด, เครื่องดื่มพิเศษ, เบเกอรี่โฮมเมด, แพ็กเกจพื้นที่ (มีคลาส category-btn และปุ่มแรกใส่คลาส active)
  3. บล็อกสินค้ากริดการ์ด (menu-grid):
    • ใช้แท็ก <section class="menu-grid"> ภายในประกอบด้วยสินค้า 6 ชิ้น ครอบด้วยแท็ก <article class="menu-card">
    • โครงสร้างในการ์ดแต่ละใบ:
      • <div class="card-img-container"> บรรจุภาพ <img src="..."> และฉลากระบุโปรโมชันพิเศษ (ถ้ามี) <span class="card-badge [seasonal / bestseller / chef / hot]">
      • <div class="card-content"> บรรจุหัวข้อ <h3>, คำอธิบายยาว <p class="card-desc">, และ <div class="card-footer"> ที่ใส่ราคาสินค้า .price และปุ่มจอง .btn

3. หน้าฟอร์มจองสัมมนา midterm-booking.html (10 คะแนน)

เขียนโครงสร้างหน้าแบ่งฝั่งซ้ายขวา (Split Layout) ซีกซ้ายวางแผนผังร้านด้วยเวกเตอร์ SVG และฝั่งขวาทำแบบฟอร์มที่มีปุ่มตัวเลือกแบบ Custom Radio Cards และสวิตช์ Toggle Custom

🔍 โครงสร้าง HTML ที่ต้องเขียนขึ้นเองภายใน body:

  1. ส่วนสปลิทแบ่งข้าง (split-layout):
    • ใช้แท็ก <main class="container page-content"> คุมด้านนอก ถัดมามี <div class="split-layout">
  2. ฝั่งซ้าย: นโยบายและแผนผัง SVG (aside):
    • ใช้แท็ก <aside class="info-sidebar"> ภายในมี <div class="info-card"> บรรจุหัวเรื่อง รายละเอียดนโยบายจอง และข้อมูลติดต่อ
    • มีกล่องครอบแผงจำลองที่นั่ง <div class="info-card map-card"> บรรจุข้อมูลและแผนผัง SVG โครงสร้างที่นั่งจริงด้านล่าง
  3. ฝั่งขวา: กล่องกรอกแบบฟอร์มจอง (form-container):
    • ใช้แท็ก <section class="form-container"> บรรจุแท็กฟอร์มหลัก <form action="#" method="GET" class="booking-form">
    • ช่องกรอกจัดระเบียบแบ่งครึ่งด้วยกริดแถว <div class="form-grid"> สำหรับครอบข้อมูล:
      • คู่ที่ 1: ชื่อจริง #firstname + นามสกุล #lastname
      • คู่ที่ 2: อีเมล #email + เบอร์โทรศัพท์ #phone
    • กลุ่มตัวเลือกแบบวิทยุการ์ด (radio-cards-grid):
      • สร้างกล่องหุ้ม <div class="radio-cards-grid"> ด้านในมีตัวเลือก 3 บล็อกคลาส radio-card-wrapper
      • โครงสร้างย่อย: แท็กอินพุตวิทยุจริง <input type="radio" id="pkg-desk" name="package-option" value="hotdesk" checked required> และแท็กแสดงการ์ด <label for="pkg-desk" class="custom-radio-card"> (ในฉลากมีกล่องใส่ไอคอนอารมณ์ .radio-icon, ชื่อเรื่อง .radio-title, ราคา .radio-price และรายละเอียดสั้น .radio-desc)
    • แถววันเวลาแบบ 3 ช่องย่อย:
      • ใช้คลาส <div class="form-grid col-3"> บรรจุวันจอง #book-date (ชนิด date) + เวลาจอง #book-time (ชนิด time) + จำนวนแขก #guests (แท็ก select)
    • สวิตช์เลื่อนปุ่ม (Custom Toggle Switch):
      • จัดรวมในกล่องคลาส <div class="toggle-group">
      • มีรางควบคุมสไลด์ <label class="switch-container"> บรรจุอินพุตตรวจสอบ <input type="checkbox" id="subscribe"> และรางสไลด์ <span class="switch-slider"></span>
      • ป้ายข้อความข้างกัน <label for="subscribe" class="toggle-label"> ต้องการรับข้อมูลข่าวสารผ่านทางอีเมล
