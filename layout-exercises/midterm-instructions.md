# 📝 โจทย์จำลองข้อสอบปฏิบัติกลางภาค: Web Layout & Design
**วิชา**: Web Development & CSS Styling (ระดับความท้าทายกลาง-สูง)
**เวลาทำโจทย์แนะนำ**: 3 ชั่วโมง (สามารถแบ่งทำทีละวันเพื่อการฝึกฝนได้)
**หัวข้อ**: ระบบหน้าเว็บข้อมูลร้าน รายการเมนู และการจองโต๊ะของ **Flora & Fauna - Botanical Cafe & Glasshouse**

---

## 🌟 จุดประสงค์การทดสอบ (Core Competencies)
โจทย์นี้ออกแบบขึ้นเพื่อวัดผลความรู้และทักษะการจัดหน้าเว็บด้วย HTML5 และ CSS3 ขั้นสูงที่มักเจอในข้อสอบกลางภาคของมหาวิทยาลัย โดยเน้นประเด็นสำคัญดังนี้:
1. **Semantic HTML5**: การจัดโครงสร้างหน้าเว็บที่ถูกต้องตามโครงสร้างการนำทางและการเข้าถึงข้อมูล
2. **Sticky Navigation & Blurry Backdrop**: การทำ Layout ที่มีส่วนหัวตรึงอยู่กับที่พร้อมเอฟเฟกต์กระจกฝ้า
3. **CSS Grid (Asymmetrical Gallery)**: การวาง Layout รูปภาพขนาดต่างกันให้ประสานกันพอดีโดยใช้ Grid Spans
4. **CSS Flexbox (Card Equal Alignment)**: การจัดการให้ปุ่มและเนื้อหาด้านล่างการ์ดอยู่ในระดับเดียวกัน แม้คำบรรยายจะสั้นยาวไม่เท่ากัน
5. **CSS Advanced Selectors & Custom Interactive Components**: การแต่งฟอร์มจองด้วย CSS ตัวเลือกสถานะ เช่น `:checked` และ Selector พี่น้อง (`+` / `~`) เพื่อทำปุ่ม Radio Card และ Switch Toggle โดยไม่พึ่งพา JavaScript
6. **Responsive Web Design (Mobile-First หรือ Desktop-First)**: การปรับเลย์เอาต์หน้าจอให้รองรับหน้าจอคอมพิวเตอร์ แท็บเล็ต และมือถือได้อย่างสมบูรณ์

## 📂 โครงสร้างโปรเจกต์
ในแบบฝึกหัดนี้จะมีไฟล์ที่เกี่ยวข้องดังนี้:

* `midterm.css` - ไฟล์สไตล์ชีต (ผู้สอบต้องเขียนคำสั่งสไตล์เลย์เอาต์ที่นี่)
* `midterm-solution.css` - เฉลยอย่างละเอียด (เอาไว้ดูแนวคิดเมื่อหมดเวลาหรือต้องการเปรียบเทียบคำตอบ)

## 🏆 รายละเอียดของงานและเกณฑ์การให้คะแนน (คะแนนเต็ม 30 คะแนน)

### 📌 ตอนที่ 1: ระบบนำทางส่วนกลาง (Shared Navigation Bar) — [3 คะแนน]
*หน้าเว็บทั้ง 3 หน้าจะต้องใช้สไตล์แถบเมนูชุดเดียวกันซึ่งควบคุมผ่าน `midterm.css`*
1. **Sticky Header**: ส่วนหัวเว็บ (`header.navbar`) ต้องมีขนาดความสูงที่เหมาะสม และถูกตรึงไว้ด้านบนสุดของหน้าจอเสมอเมื่อเลื่อนดูเนื้อหาลงมา (`position: sticky; top: 0; z-index: 100;`)
2. **Glassmorphism Effect**: พื้นหลังของแถบนำทางต้องมีความโปร่งใสเล็กน้อย ร่วมกับการใช้เอฟเฟกต์เบลอภาพพื้นหลังด้านหลังแถบนำทาง (`backdrop-filter: blur(10px); background-color: rgba(255, 255, 255, 0.8);`)
3. **Menu Links**: การจัดวางโลโก้อยู่ฝั่งซ้าย และลิงก์นำทางทั้ง 3 หน้าอยู่ฝั่งขวา (โดยใช้ Flexbox)
4. **Active Link Style**: หน้าเว็บที่เปิดอยู่ในขณะนั้น ลิงก์ที่ตรงกับหน้านั้นจะต้องมีคลาส `.active` ซึ่งจะแสดงสไตล์แตกต่างจากลิงก์อื่นๆ เช่น มีเส้นใต้ หรือสีตัวอักษรที่เข้มกว่า

### 📌 ตอนที่ 2: หน้าข้อมูลร้าน (`midterm-shop.html`) — [7 คะแนน]
1. **Hero Banner section**:
   - การจัดข้อความหลัก (Headline), คำอธิบายย่อย และปุ่ม Call-to-action (ปุ่ม "จองโต๊ะเลย") ให้อยู่ตรงกึ่งกลางของแบนเนอร์เสมอ โดยใช้ภาพพื้นหลังที่มี Filter มืดทับเพื่อให้ข้อความสีขาวอ่านได้ชัดเจน
2. **Bento Grid Gallery (อสมมาตร)**:
   - จัดวางแกลเลอรีรูปภาพจำนวน 5 รูปให้เรียงกันแบบ Grid ที่มีความสูงและความกว้างที่เหมาะสม โดยมีสัดส่วนแถวและคอลัมน์ที่ไม่เท่ากัน (ตัวอย่าง Layout ข้อสอบ):
     * รูปที่ 1 (ภาพร้านหลัก): กว้างกิน 2 คอลัมน์ และ สูงกิน 2 แถว (`grid-column: span 2; grid-row: span 2;`)
     * รูปที่ 2 (โซนกาแฟ): กว้าง 1 คอลัมน์ และ สูงกิน 2 แถว
     * รูปที่ 3 (สวนป่าไม้): กว้าง 1 คอลัมน์ และ สูง 1 แถว
     * รูปที่ 4 (เบเกอรี่): กว้าง 1 คอลัมน์ และ สูง 1 แถว
     * รูปที่ 5 (ที่นั่งทำงาน): กว้างกิน 2 คอลัมน์ และ สูง 1 แถว
3. **Responsive Grid**: เมื่อแสดงผลบนอุปกรณ์ขนาดเล็ก (จอต่ำกว่า 768px) แกลเลอรีนี้จะต้องยุบตัวลงมาเหลือเรียงเป็น 1 คอลัมน์แนวตั้งทั้งหมด

### 📌 ตอนที่ 3: หน้ารายละเอียดเมนูและการจองบริการ (`midterm-menu.html`) — [10 คะแนน]
1. **Filter Categories Layout**:
   - จัดแถบเลือกหมวดหมู่เมนู ("ทั้งหมด", "เครื่องดื่ม", "ขนมหวาน", "พื้นที่ทำงาน") ให้อยู่กึ่งกลางหน้าจอโดยมีระยะห่างพอดี ใช้ Flexbox ในการเรียงตัว
2. **Responsive Menu Grid**:
   - หน้าจอเดสก์ท็อป: แสดงผลแบบ Grid กว้าง 4 คอลัมน์
   - หน้าจอแท็บเล็ต: แสดงผลแบบ Grid กว้าง 2 คอลัมน์
   - หน้าจอมือถือ: แสดงผลแบบ Grid กว้าง 1 คอลัมน์
3. **Card Component & Absolute Positioning**:
   - การ์ดอาหารแต่ละชิ้นจะต้องมี Badge ป้ายราคาหรือสัญลักษณ์บอกสถานะสินค้า (เช่น "Recommended", "New", "Chef's Special") แปะอยู่ที่มุมขวาบนของภาพ โดยใช้ `position: absolute` และมีขอบมนพร้อมสีพื้นหลังที่ชัดเจน
4. **Equal Height Card Footer (Flexbox Challenge)**:
   - การ์ดทุกใบต้องมีความสูงเท่ากันในแถวเดียวกัน
   - โครงสร้างภายในของการ์ด (รูปภาพ, ชื่อเมนู, คำอธิบายสั้นๆ, และข้อมูลราคาพร้อมปุ่มสั่งจองที่อยู่แถวล่างสุด) ต้องได้รับการจัดระบบด้วย Flexbox แนวตั้ง (`flex-direction: column`)
   - **โจทย์หลัก**: ดันให้ "ราคาและปุ่มสั่งจอง" วิ่งลงไปชนขอบล่างสุดของการ์ดเสมอ แม้ว่าการ์ดบางใบจะมีข้อความคำอธิบายสั้นกว่าใบอื่นๆ
5. **Hover Interaction Effect**:
   - เมื่อผู้ใช้นำเมาส์ไปชี้ที่การ์ดเมนู (Hover state) ตัวการ์ดจะต้องมีเอฟเฟกต์ยกตัวลอยขึ้นเบาๆ (`transform: translateY(-8px);`) พร้อมทั้งเงาการ์ดฟุ้งขยายขึ้น และปุ่มสั่งซื้อมีการขยายขนาดหรือเปลี่ยนโทนสีด้วย CSS `transition` ที่นุ่มนวล (0.3 วินาที)

### 📌 ตอนที่ 4: หน้าแบบฟอร์มการจองโต๊ะ (`midterm-booking.html`) — [10 คะแนน]
1. **Two-Column Split Layout**:
   - ในหน้าจอเดสก์ท็อป ให้แบ่งสัดส่วนหน้าเว็บออกเป็น 2 ฝั่งซ้าย-ขวา (เช่น 35% : 65% หรือ 40% : 60%) ฝั่งซ้ายโชว์รายละเอียดข้อมูลการบริการและกฎการจอง ฝั่งขวาแสดงส่วนฟอร์มจองข้อมูล
   - เมื่อแสดงในอุปกรณ์มือถือ เลย์เอาต์ทั้งสองฝั่งต้องยุบมาต่อเป็นแนวตั้งอย่างสวยงาม
2. **Form Layout via CSS Grid**:
   - ภายในฟอร์มจองโต๊ะ ให้ใช้ CSS Grid ในการจัดตำแหน่ง input fields เช่น ช่อง "ชื่อจริง" และ "นามสกุล" อยู่แถวเดียวกันแบ่งกันคนละครึ่ง, ช่อง "วัน" และ "เวลา" อยู่แถวเดียวกัน และช่อง "ความต้องการพิเศษ" ยืดเต็มแถว
3. **Pure CSS Custom Radio Cards (ความท้าทายระดับเทพ)**:
   - ตัวเลือกแพ็กเกจพื้นที่จอง (เช่น Hot Desk, Meeting Room, Glasshouse Garden Zone) จะแสดงผลในรูปแบบการ์ด 3 ใบเรียงติดกัน
   - **กติกา**: ห้ามให้เห็นปุ่มกลมๆ ของ `<input type="radio">` แบบดั้งเดิม (ให้ใช้วิธีซ่อนมันด้วย CSS เช่น `opacity: 0; position: absolute;`)
   - จัดการตกแต่งกล่องฉลาก `<label>` ที่ตามหลัง input ให้แสดงเป็นกรอบการ์ดสวยงาม
   - เมื่อผู้ใช้คลิกเลือกการ์ดใบใดก็ตาม (สถานะตัวเลือกเป็น `:checked`) ให้เขียน CSS เพื่อเปลี่ยนสไตล์ของการ์ดตัวนั้น เช่น กรอบเปลี่ยนสีเป็นโทนเข้ม หนาขึ้น หรือมีสีพื้นหลังเรืองแสงขึ้นมาโดยใช้ Selector เช่น `input[type="radio"]:checked + .card-label`
4. **Pure CSS Toggle Switch**:
   - ออกแบบช่องติ๊กเลือกรับอีเมลข่าวสารให้กลายเป็นปุ่มสวิตช์เปิด-ปิดแบบเม็ดยาเลื่อนซ้ายขวา (Toggle Switch) โดยใช้เฉพาะ HTML CSS เคลื่อนย้ายลูกกลมๆ ด้านในด้วยตัวเลือก `input[type="checkbox"]:checked + .slider::before`
5. **Interactive Focus & Validation Visual Style**:
   - สำหรับช่องป้อนข้อมูล (Input text, select) ที่เปิดโหมด `required` หากกรอกค่าผ่านเกณฑ์หรือไม่ได้กรอกข้อมูลให้ขึ้นแสดงเส้นกรอบที่เปลี่ยนสีให้ชัดเจนเมื่อจับโฟกัส (`:focus` หรือ `:valid`)
